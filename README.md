# Bot de Afiliado — versões

Aqui ficam apenas os **instaladores** do Bot de Afiliado. O aplicativo instalado confere este endereço para se atualizar sozinho.

**Para instalar:** abra a [última versão](../../releases/latest), baixe `Bot-de-Afiliado-Instalador.exe` e abra o arquivo. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.

Depois de instalado, o app avisa quando houver versão nova e se atualiza com um clique.
